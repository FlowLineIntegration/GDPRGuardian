# Sécurité / Security

**Français.** Ne signalez jamais une faille dans une issue publique. Utilisez le signalement privé de GitHub :
[Report a vulnerability](https://github.com/FlowLineIntegration/GDPRGuardian/security/advisories/new), ou écrivez à
`contact@gardienrgpd.fr`. Décrivez le problème avec des données fictives uniquement. Nous accusons réception sous
sept jours et publions un correctif avant toute divulgation.

**English.** Never report a vulnerability in a public issue. Use GitHub private reporting:
[Report a vulnerability](https://github.com/FlowLineIntegration/GDPRGuardian/security/advisories/new), or write to
`contact@gardienrgpd.fr`. Describe the problem with fictitious data only. We acknowledge within seven days and ship
a fix before any disclosure.
